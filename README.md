# سينمانا TV

تطبيق Android TV لمشاهدة محتوى [سينمانا](https://cinemana.shabakaty.com/) بالريموت.

هذا المستودع للإصدارات فقط، ومنه يحمّل التطبيق تحديثاته.

## التحميل

**[تحميل آخر إصدار (CinemanaTV.apk)](https://github.com/ahmedalaa741741-ui/cinemana-tv/releases/latest/download/CinemanaTV.apk)**

كل الإصدارات وما الجديد في كل منها: [صفحة الإصدارات](https://github.com/ahmedalaa741741-ui/cinemana-tv/releases)

## التثبيت أول مرة

1. على التلفزيون: الإعدادات ← الأمان/الخصوصية ← السماح بتثبيت التطبيقات من **مصادر غير معروفة**.
2. انقل `CinemanaTV.apk` إلى التلفزيون (فلاشة، أو تطبيق Send Files to TV، أو `adb install -r CinemanaTV.apk`) وثبّته.

## التحديث

من الإصدار 2.2 فصاعداً يتحدث التطبيق من داخل التلفزيون:

- عند فتح التطبيق يتحقق من وجود إصدار جديد ويعرض «تحديث الآن».
- أو من **الإعدادات ← تحديث التطبيق**.

يحمّل التطبيق الملف من هنا ويفتح نافذة التثبيت، وتبقى قائمتك وسجل مشاهدتك كما هي.

> الخدمة تعمل عبر شبكات الإنترنت العراقية فقط (مثل موقع سينمانا نفسه).
